# API Reference

This section is generated by `mkdocstrings` directly from the Python source docstrings and covers the **public interface**. Users only need `schedflow.core`, `schedflow.triggers` and `schedflow.api.rest`.

## P0 behavior notes (priority / cancellation / one-shot jobs)

- `Job` gains `priority` (default `0`; lower values dispatch first);
- New `POST /api/jobs/{job_id}/cancel` endpoint: `409` when the job is neither
  queued nor running, `404` when it does not exist;
- `Job.status` supports `completed`: exhausted one-shot jobs stay in the store
  with scheduling stopped instead of being removed automatically;
- `POST /api/jobs` and `PUT /api/jobs/{job_id}` accept `priority`.

## P1 behavior notes (run snapshots / resume / timeout)

- `POST /api/jobs/{job_id}/run` accepts `{"mode": "full"|"resume", "timeout": seconds}`;
  resume without a snapshot or with a changed DAG returns 409;
- `GET /api/jobs/{job_id}/runs` returns run summaries (execution_id / mode /
  resumes_from / status / started_at / ended_at);
- `GET /api/jobs/{job_id}/runs/{execution_id}` returns the RunSnapshot while the
  run is active and the ExecutionLog afterwards;
- `ExecutionLog` gains `mode` and `resumes_from`; `TaskRecord` gains `resumed`.

## P2 behavior notes (observability and integrations)

- `GET /api/metrics`: Prometheus text format with no extra dependency;
- `GET /api/v1/sse/jobs/{job_id}/events`: `job.*` / `task.*` event stream;
- `GET/PUT /api/v1/settings/webhooks`: webhook subscription settings;
- `GET/PUT /api/v1/settings/rate-limit`: write-request rate limiting (off by
  default; 429 + `Retry-After` when exceeded);
- `SCHEDFLOW_LOG_FORMAT=json` enables structured JSON logs.
